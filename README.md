# Smart Tours & Travels Analytics

## Project Overview

Smart Tours & Travels Analytics is a travel booking and customer analytics project developed to analyze booking data and understand revenue trends, package performance, agent performance, customer types, cities, vehicle usage, and financial performance.

The project uses **Google Sheets** for data preparation and analysis and **Looker Studio** for dashboard visualization.

## Business Objectives

* Analyze overall travel booking performance
* Track revenue and booking trends
* Understand package-wise performance
* Analyze agent performance
* Compare revenue across cities
* Understand customer types
* Analyze vehicle usage
* Monitor discounts and revenue
* Compare gross and net revenue
* Analyze travelled vs refunded bookings

## Tools Used

* Google Sheets
* Looker Studio

## Dataset

The dataset contains **3,001 travel booking records** with information related to customers, agents, travel packages, cities, revenue, ratings, discounts, vehicles, and booking outcomes.

## Dashboard Sections

### 1. Executive Overview

The executive dashboard provides an overview of:

* Revenue by customer type
* Monthly revenue trend
* Revenue by package
* Revenue by city
* Vehicle usage split
* Customer type distribution

### 2. Agent Performance

This section analyzes:

* Bookings per agent
* Revenue per agent
* Average rating per agent
* Monthly revenue by agent
* Agent performance summary

### 3. Package Analytics

This section analyzes:

* Bookings by package
* Average rating by package
* Monthly revenue by package
* Package performance by city

### 4. Financial Dashboard

This section analyzes:

* Gross vs net revenue
* Revenue vs discount trends
* Travelled vs refunded bookings
* Profit vs cost trends
